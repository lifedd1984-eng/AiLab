## 프로젝트 정의

윤아를 둘러싼 존재들(사람·시간·능력·가치·경험·환경)과 그 관계를 명시적으로 정의하고, 19개월부터 20세까지 관측 기록과 결정 이력을 그 구조 위에 쌓아 판단 근거로 쓰는 20년짜리 부부+클대리 공동 작업. 정식 이름 미확정(조 팀장 명명 예정).

- 구조 3층: 가치층(왜) / 관측층(무엇, 해석 없는 날것) / 판단층(어떻게, 결정 이력)
- 가치층은 3축: 지향(잘 키운다, 1부) / 금지(잘못 키우지 않는다, 2부) / 관계(연결 유지, 공동세션)
- 핵심 통찰(조 팀장): "잘 키운다는 포괄적이지만 잘못 키우는 방식은 한정적" → 금지 축이 먼저 집행 가능
- 문체 규칙: 형식적·오글거리는 표현 금지, 건조한 평서문. 서약·소감 문항 금지
- 성공 기준: 20년 뒤 윤아가 이 기록을 감시가 아니라 선물로 받아들이는 것 (7세 열람권, 13세 정정·거부권, 성인 시 소유권 이전)

## 2026-09-03 방향 변경

조 팀장 확인 기준으로 부모 가치관 질문지 1·2부 단계는 종료한다. 기존 분석의 미해결 항목은 기록으로 남기되, 현재 작업 순서를 막지 않는다.

이제 만드는 것은 **윤아의 20개월부터 고3까지 시기별 양육 로드맵**이다. 각 시기는 아래 8개로 구성한다.

1. 정상 발달 범위와 상담 신호
2. 부모가 해야 할 것
3. 하지 말아야 할 것
4. 해줘야 할 말과 대화
5. 음식·수면·운동·스크린
6. 필요한 경험과 놀이
7. 건강검진·안전
8. 윤아의 실제 상태와 다음 목표

## 분석 v1 핵심 (분석_아빠_v1.md)

- **T1 (최우선)**: A1 이상("가감 없이 이야기하는 딸", B5 부모 먼저 연락) ↔ I-3 습관("괜찮아 울지 마", 빨리 잊게 하기) 정면 충돌. 처방: "울 만했네" 한 문장을 앞에 끼우기
- **T2**: C1 사과 원칙 ↔ H1 체벌 가능성 — 레드라인 1번과 충돌, 공동세션 서약 전 정리 필요
- **T3**: 트리거 외부 귀인("윤아 때문") ↔ C1에선 "지친 저녁" 인정 — 본인 상태 요인 미탐색
- **T4**: B3=1(말 잘 듣는) + 유일 트리거 "말 안 들을 때" = 급소. A1(가감 없는 말)과 사춘기쯤 충돌 예정
- **T5**: 자유 지지의 조건부 구조 (문제라기보다 자기 인식용)
- 강점: 사과가 첫 반응 / 원가족 인식→구체 지향 변환 / 숫자 회피 없음 / 시간 우선순위(조기 은퇴)

- **트리거 특정**: "같은 말을 세 번쯤 반복했을 때"

**답변 대기 중** — 클대리가 제안한 규칙: *같은 말은 두 번까지만 한다. 두 번째에 안 되면 말을 멈추고 몸으로 간다(걸어가서 손 잡고 같이 하기).*
1. 3회차에 올라오는 감정이 "내 말이 무시당했다"가 맞는가
2. 두 번 상한이 실제로 지킬 만한가 (못 지킬 것 같으면 세 번으로 하고 4회차를 막는 게 나음)

이 규칙이 서면 T2도 풀린다 — 서약을 "때리지 않겠다"(검증 불가)에서 "세 번 반복하지 않겠다"(셀 수 있음)로 전환 가능.

**미해결**: T2(서약 vs 체벌 가능성), T4(말 안 들음이라는 급소), T5(자유 지지의 조건부 구조)

## 2026-09-03 로드맵 v1 부모 검토 반영

조 팀장·사모님이 20개월 현재 상태를 공동 확인했고 그 결과를 로드맵 v1에 반영했다.

- **해소**: 수면 총 12~14시간(범위 안, 우려 없음) / 대근육은 강점(혼자 걷기·뛰기·계단·공 차기·던지기 다 됨) / 지시 이해·그림책 가리키기는 강점 / 숟가락은 정상 연습 단계
- **표현 언어**: 단어 10개 이내, 두 단어 연결 아직. 20개월엔 정상이나 증가 추적. 22개월에 증가 없으면 검진일 전 언어·청력 상담
- **새로 드러난 우선 과제 1 — 우유·젖병·야간수유**: 우유 500ml를 취침~새벽 나눠 먹고 누워서 젖병 물고 잠. 우유병 우식증·질식·중이염·수면 분절 위험, 밤중 수유는 이 나이에 영양상 불필요. 조치: 양치를 마지막 순서로, 자기 전은 앉아서 컵, 누워서 물고 자기 우선 중단, 야간은 물, 젖병→컵 전환. 4차 검진·치과에서 충치 여부 확인
- **새로 드러난 우선 과제 2 — 때리기·꼬집기**: 부모·조부모·또래 대상, 매일, 경미한 부상. 때린 뒤 태연(결과 미연결, 20개월엔 정상). 언어 미발달과 연결. 조부모가 웃음·혼냄을 섞어 반응 → 때리기가 어른 반응 스위치가 됨. 대응 초안(때리려는 순간용/때린 뒤용 4단계 + 조부모 최소 버전 + 어린이집 문장 통일 + 하지 않을 것)을 로드맵 2번에 정리. C3(조부모 훈육 뒤집기)와 직결. 담임이 쓰는 말·절차는 조 팀장이 확인해 채울 항목
- **4차 영유아 건강검진**: 미실시(기간 내). 예약 필요, 문진에 우유·때리기 기재

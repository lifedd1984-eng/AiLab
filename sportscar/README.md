# 🏎️ 스포츠카 무한 질주

야간 도로를 달리며 다가오는 차를 피하는 탑뷰 엔들리스 레이싱 게임입니다.

> 차고에서 차와 배경을 고른다 → 화면 왼쪽/오른쪽을 탭해서 차선을 바꾼다
> → 다가오는 차를 피하며 버틴다 → 아슬아슬하게 스치면 니어미스 콤보 보너스
> → 부딪히면 게임오버, 달린 거리와 코인 저장 → 코인으로 새 차 해금

## 어떻게 실행해?

`index.html`을 더블클릭하면 끝입니다. 설치할 것도, 인터넷도 필요 없어요.
휴대폰에서도 그대로 돌아갑니다.

## 어떻게 노는 거야?

1. 차고에서 **차**(기본: 옐로우 선더)와 **배경**(도시 야경 / 사막 야경)을 고르고 "출발!"
2. 화면 **왼쪽/오른쪽을 탭**해서 차선을 바꿉니다 (4차선)
3. 다가오는 차에 부딪히면 **즉시 게임오버**
4. **바로 옆 차선의 차를 아슬아슬하게 스치면** "니어미스" 보너스! 연속으로 스치면 콤보 배수가 붙습니다
5. 시간이 지날수록 **차가 더 자주 나타납니다** (난이도의 주된 축). 속도도 아주 조금씩 빨라집니다 (보조 축)
6. 달린 거리만큼 **코인이 자동으로 쌓이고**, 코인으로 다른 차를 살 수 있습니다
7. **800m**를 달성하면 사막 야경 배경이 열립니다

## 확정 기획과 대응 관계

| 기획 항목 | 구현 |
|---|---|
| 탑뷰 / 장애물 피하며 버티기 | 4차선 탑뷰, 충돌 시 즉시 게임오버 |
| 화면 좌/우 탭 조향 | `stage`에 pointerdown, 절반 기준으로 차선 ±1 |
| 야경 테마 2종 | 도시 야경(기본) · 사막 야경(800m 해금) |
| 장애물 증가형 난이도 | `spawnIntervalAt()` — 시간이 지날수록 스폰 간격이 짧아짐 (1250ms → 520ms) |
| 속도 상승은 보조 | `speedMulAt()` — 12초마다 +0.12배, 최대 1.9배로 완만하게 |
| 슈퍼카 4종, 디자인 차등 | 쐐기형(레드) · 머슬(옐로우, 기본) · GT(블루) · 랠리(그린) |
| 니어미스 콤보 | 1.8초 안에 연속으로 스치면 콤보 배수 증가, 보너스 코인 |
| 최고 기록 + 코인 저장 | `localStorage` |

## 조카들과 같이 고치는 법

### 1. 새 차 추가하기

`CARS` 목록에 추가하고, `drawCar()`에 새 `type` 분기를 하나 더 만들면 됩니다.
기존 4종(`wedge`/`muscle`/`gt`/`rally`)의 코드를 그대로 복사해서 좌표만 바꿔보세요.

```js
{ id: "newcar", name: "새 차 이름", accent: "#ff00ff", cost: 1000, concept: "설명" },
```

### 2. 난이도 조절하기

```js
var SPAWN_START = 1250, SPAWN_MIN = 520, SPAWN_DECAY = 0.018; // 장애물 스폰 간격(ms)
var SPEED_STEP_MS = 12000, SPEED_STEP = 0.12, SPEED_MAX = 1.9;  // 속도 상승 폭
```

- 너무 어렵다 → `SPAWN_MIN`을 올리거나 `SPAWN_DECAY`를 낮추세요 (장애물이 덜 빡빡해짐)
- 너무 쉽다 → `SPAWN_START`를 낮추세요 (처음부터 더 자주 나옴)

### 3. 경제 밸런스 조절하기

```js
var COIN_PER_M = 1 / 20;              // 20m 당 코인 1개
var DESERT_UNLOCK_M = 800;            // 사막 해금 거리
var NEARMISS_COMBO_WINDOW = 1800;     // 니어미스 콤보 유지 시간(ms)
```

니어미스 보너스는 `triggerNearMiss()`에서 `40 * comboCount`로 계산됩니다.

### 4. 새 배경 테마 추가하기

`THEMES` 객체에 하나 더 추가하고, `drawFrame()`의 `if (themeId === "city") {...} else {...}` 분기를
`else if`로 늘려서 그 테마 전용 배경 그리기 코드를 넣으면 됩니다. 도시(빌딩)와 사막(듄+선인장+바위)
코드를 참고하면 세 번째 테마도 비슷한 패턴으로 만들 수 있어요.

## 기술 메모

- 파일 하나짜리 HTML. 외부 라이브러리 없음, 이미지 파일 없음(전부 캔버스로 직접 그림), 소리도 코드로 직접 생성
- 자동차는 탑뷰 실루엣을 베지어 곡선으로 그리고, 유광 도장 그라디언트 + 좌상단 유광 하이라이트 스트로크로
  질감을 냅니다 (`paintGradient` / `finishBodyStroke`)
- 충돌 판정은 픽셀 단위가 아니라 **차선 인덱스 기반**입니다. 같은 차선에서 y좌표가 겹치면 충돌,
  바로 옆 차선에서 겹치면 니어미스로 처리합니다. 아이들이 하기에 더 예측 가능하고 억울하지 않습니다
- 장애물마다 `resolved` / `nearMissDone` 플래그로 한 번만 판정되게 막습니다. 안 막으면 화면을
  가로지르는 여러 프레임 동안 같은 차에 대해 판정이 중복 발생합니다
- 배경 장식(빌딩/듄/선인장/바위/모래바람/스피드 라인)은 게임 시작 시 한 번만 시드를 만들고,
  매 프레임 `scrollY` 기반으로 위치만 계산합니다. 배경 요소마다 패럴랙스 배율이 달라서
  (먼 능선 0.22배, 가까운 능선 0.4배, 차선/장애물 1배) 깊이감이 생깁니다
- 진행 상황은 `localStorage`(`supercar-night-rush-v1`)에 저장됩니다 (타이틀 화면에서 초기화 가능)
- `window.__scGame`은 자동화 테스트를 위한 훅입니다. 실제 플레이에는 영향을 주지 않고
  상태 확인과 시나리오(니어미스/충돌) 유발만 합니다

# 시나리오 뱅크 — 투자 철학을 끌어내는 질문들

멘토는 이 상황들을 **한 번에 하나씩** 던지고, 사용자의 답을 듣고, 답 속에
숨은 원칙을 언어화해 `my-principles.md`에 채워 넣는다. 순서대로 다 할 필요
없다. 사용자 상태와 관심사에 맞게 고른다. 각 시나리오 끝의 `→`는 이 답이
어느 원칙 항목으로 정리되는지 표시.

## A. 시장 과열 / 포모 (FOMO)
1. "친구가 어떤 종목으로 3배 벌었다고 자랑해요. 지금이라도 들어가고 싶어요.
   당신이라면 어떻게 하겠어요?" → 5. 매수 규칙 / 8. 감정 신호
2. "지수가 사상 최고가를 매일 갱신 중이고 뉴스는 온통 '지금 안 사면 바보'
   분위기예요. 이럴 때 당신의 원칙은?" → 3. 자산배분 / 5. 매수 규칙
3. "사고 싶던 종목이 3일 만에 30% 급등했어요. 추격매수할까요, 기다릴까요?
   기준이 뭐예요?" → 4. 포지션 / 5. 매수 규칙

## B. 폭락 / 공포 / 패닉셀
4. "하루아침에 -20% 폭락했어요. 계좌를 보는 게 무서워요. 팔아서 더 잃는 걸
   막고 싶은 마음이 드는데, 미리 정해둘 규칙이 있다면?" → 6. 매도 / 8. 감정
5. "폭락장이 왔어요. 이건 위기일까요 기회일까요? 당신은 이럴 때 사는 사람인가요
   지키는 사람인가요? 그러려면 무엇이 준비돼 있어야 하죠?" → 3. 자산배분(현금)
6. "-40%인 종목을 물타기할까 고민돼요. 어떤 경우엔 되고 어떤 경우엔 안 되나요?"
   → 4. 포지션 / 6. 매도

## C. 집중 vs 분산 (몰빵)
7. "확신이 아주 강한 종목이 하나 있어요. 자산의 몇 %까지 넣는 게 당신에게
   편안한가요? 그 이유는?" → 4. 포지션 규칙
8. "한 종목이 크게 올라서 어느새 전체의 50%가 됐어요. 그대로 둘까요, 덜어낼까요?"
   → 3. 자산배분 / 6. 리밸런싱

## D. 목적·기간·위험
9. "이 투자금은 언제 쓸 돈인가요? 3년 뒤 반토막 나 있어도 삶에 문제가 없나요?"
   → 1. 목적·기간 / 2. 위험 성향
10. "'하루에 -10%'와 '평생 -50% 한 번'. 어느 쪽이 더 견디기 힘든가요?"
    → 2. 위험 성향

## E. 정보·소음·확신
11. "유튜버/리딩방/뉴스가 강하게 추천해요. 당신은 남의 확신을 얼마나 신뢰하나요?
    스스로 이해 못 하는 걸 사도 되나요?" → 7. Never 리스트
12. "레버리지·빚투로 수익을 키울 기회가 보여요. 당신의 선은 어디인가요?"
    → 7. Never 리스트

## F. 시장 심리 읽기
13. "택시기사·주변 비전문가까지 다 주식 얘기를 해요. 이 신호를 당신은 어떻게
    해석하나요?" → 3. 자산배분(과열 판단) / insights 참고
14. "공포·탐욕 지수가 '극단적 탐욕'이에요. 이럴 때 당신의 행동 규칙은?"
    → 3. 자산배분 / 5. 매수

## G. 자기 심리 (메타인지)
15. "지난번에 원칙을 어기고 감정적으로 매매한 적 있나요? 그때 어떤 감정이
    방아쇠였어요?" → 8. 감정 신호
16. "당신이 가장 실수하기 쉬운 순간은 언제인가요? 그 순간을 어떻게 알아챌 수
    있을까요?" → 8. 감정 신호 (나만의 브레이크)

---

## 진행 팁
- 답을 들으면 **되받아 요약**한다: "정리하면, 당신은 ~한 사람이군요. 맞나요?"
- 확정되면 원칙 문장으로 만들어 `my-principles.md` 해당 항목에 기록.
- 모순되는 답(예: "장기투자자"라면서 "3일 급등에 추격")이 나오면 부드럽게
  짚어주고 사용자가 스스로 정리하게 한다.
- 한 세션에 3~5개 정도가 적당. 강요하지 않는다.

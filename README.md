# 🍜 식당 대소동 — 사장님 물건 찾기

삼촌과 조카들이 함께 만드는 **숨은 물건 찾기 게임**입니다.

> 식당에 들어간다 → 가게를 둘러보며 **냉장고·서랍·상자를 열어서** 물건을 찾는다
> → 사장님한테 주고 코인 획득 → 레벨업 → 새 식당 해금

## 어떻게 실행해?

`index.html` 파일을 더블클릭하면 끝입니다. 설치할 것도, 인터넷도 필요 없어요.
휴대폰에서도 그냥 돌아갑니다.

## 어떻게 노는 거야?

1. 가게를 **옆으로 밀어서** 주방 → 카운터 → 홀까지 둘러봅니다
2. **냉장고 · 찬장 · 오븐 · 서랍장 · 쓰레기통 · 상자** 는 눌러서 열 수 있어요 (✋ 표시)
3. 열었을 때 찾는 물건이 있으면 **눌러서 획득** — 코인 10개
4. **테이블 위 · 테이블 밑 · 선반 · 카운터 · 화분 뒤**도 잘 보세요
5. 엉뚱한 걸 누르면 **시간 3초 깎임**

## 식당 목록

난이도가 올라갈수록 **찾을 물건은 늘어나고 시간은 줄어듭니다.**
그리고 물건이 점점 더 가구 **안쪽**에 숨습니다.

| 레벨 | 식당 | 난이도 | 시간 | 찾을 물건 |
|---|---|---|---|---|
| 1 | 🍙 김밥천국 | 쉬움 | 2분 | 접시, 사람, 핸드폰 |
| 2 | 🍕 피자가게 | 보통 | 1분 40초 | 피자, 햄버거, 게임기, 옷 |
| 3 | 🍣 초밥집 | 어려움 | 1분 30초 | 숫자 7, 숫자 카드, 유튜버, 핸드폰, 접시 |
| 4 | 🥡 중국집 | 매우 어려움 | 1분 15초 | 갈비, 햄버거, 사람, 옷, 게임기 |
| 5 | 🎂 생일파티 뷔페 | 최고 | 1분 | 피자, 갈비, 숫자 7, 숫자 카드, 유튜버, 사람 |

**숨기는 요령**: 목표가 `숫자 7`이면 방해물에 `1️⃣2️⃣3️⃣...`을 잔뜩 깔고,
목표가 `옷`이면 방해물에 `👗👖🧥`을 깔아둡니다. 비슷한 것들 사이에 숨겨야 찾는 맛이 납니다.

## 조카들과 같이 고치는 법

### 1. 새 식당 추가하기 (제일 재밌는 부분)

`index.html`을 열고 `RESTAURANTS` 목록을 찾으세요. 아래를 통째로 복사해서
목록 **맨 뒤에** 붙여넣고 내용만 바꾸면 새 식당이 생깁니다.
(앞에 넣으면 해금 순서가 바뀝니다.)

```js
{
  id: "chicken",                    // 겹치지 않는 영어 이름
  name: "치킨집", emoji: "🍗",
  diff: "보통", diffClass: "d2",     // d1~d5 (색깔만 바뀜)
  time: 90,                         // 제한 시간(초)
  boss: "🧑‍🍳", bossName: "치킨 사장님",
  quest: "튀기다가 정신없어서 물건을 다 잃어버렸어!",
  praise: "최고다! 치킨 한 마리 서비스!",
  menu: ["후라이드 18000", "콜라 2000"],          // 벽에 걸린 메뉴판
  colors: { wall:"#f2c98a", wood:"#8b5a2b", floor:"#c98f5a",
            cab:"#e8e2d4", cabDoor:"#f5efe2", accent:"#ffb74d" },
  wallProps: ["🍗", "🕐"],                       // 벽 액자 / 시계
  targets: [                                     // 찾아야 하는 물건
    { emoji: "🍗", name: "치킨" },
    { emoji: "🥤", name: "콜라" }
  ],
  decoys: ["🍟","🧂","🌶️","🥗"]                  // 방해물 (비슷한 걸 넣을수록 어려움)
},
```

### 2. 가게 구조 바꾸기 (가구 배치)

`LAYOUT` 목록이 식당의 가구 배치입니다. 모든 식당이 이 구조를 같이 씁니다.

```js
{ id:"fridge", type:"door2", kind:"in", x:2, y:24, w:9, h:46, cap:4, name:"냉장고" },
```

- `kind:"in"` → **문을 열어야 보이는 곳** (진짜 숨는 자리)
- `kind:"on"` → 위에 놓여 있는 곳 (선반, 카운터, 테이블 위)
- `kind:"under"` → 밑에 굴러 들어간 곳 (테이블 밑, 화분 뒤)
- `type` → 생김새: `door2`(양문) `door1`(외문) `drawer`(서랍) `lid`(뚜껑)
  `flap`(상자) `shelf` `counter` `table` `under` `plant`
- `x y w h` → 가게 안 위치와 크기 (가게 전체가 가로 100)
- `cap` → 그 안에 물건을 몇 개까지 넣을지

### 3. 난이도 조절하기

- 너무 어렵다 → `time` 늘리기, `decoys` 줄이기
- 너무 쉽다 → `targets` 추가, 비슷하게 생긴 `decoys` 추가

물건을 가구 **안쪽**에 얼마나 숨길지는 `hideRatio` 가 정합니다:

```js
var hideRatio = [0.4, 0.6, 0.8, 1, 1][levelIdx] || 1;
```

레벨 1은 40%만 가구 안에, 레벨 4부터는 전부 가구 안에 숨습니다.

### 4. 숫자만 바꿔서 게임 느낌 바꾸기

```js
var COIN_PER_FIND = 10;   // 물건 하나 찾을 때 코인
var CLEAR_BONUS   = 50;   // 클리어 보너스
var TIME_BONUS    = 2;    // 남은 1초당 코인
var HINT_COST     = 30;   // 힌트 가격
var WRONG_PENALTY = 3;    // 헛다리 짚으면 깎이는 시간(초)
```

## 다음에 넣어보면 좋을 것 (조카들 숙제)

- [ ] 조카들이 직접 그린 그림을 이모지 대신 넣기
- [ ] 조카 목소리를 녹음해서 사장님 목소리로 넣기
- [ ] 식당마다 가구 배치를 다르게 하기 (`LAYOUT`을 식당별로 두기)
- [ ] 코인으로 살 수 있는 아이템 (시간 +10초, 힌트 할인)
- [ ] 냉장고 문을 열면 안에서 뭔가 튀어나오는 함정

## 기술 메모

- 파일 하나짜리 HTML. 외부 라이브러리 없음, 이미지 파일 없음, 소리도 코드로 직접 만듦
- 가게는 화면보다 넓어서(`220%`) 좌우로 밀어 탐색합니다
- 진행 상황은 브라우저 `localStorage`에 저장 (타이틀 화면에서 초기화 가능)
- 가구(`.furn`)에 `z-index:1`을 줍니다. 없으면 화분 뒤처럼 뒤쪽에 놓인 물건이
  바닥에 가려 눌리지 않습니다
- 문 없는 자리(선반·테이블·카운터)도 물건 담는 칸을 반드시 가구에 붙여야 합니다.
  안 붙이면 그 자리 물건이 화면에 아예 안 나옵니다

# 🍜 식당 대소동 — 사장님 물건 찾기

삼촌과 조카들이 함께 만드는 **숨은 그림 찾기 게임**입니다.

> 식당에 들어간다 → 사장님이 잃어버린 물건을 찾아준다 → 칭찬받고 코인 획득 → 레벨업 → 새 식당 해금

## 어떻게 실행해?

`index.html` 파일을 더블클릭하면 끝입니다. 설치할 것도, 인터넷도 필요 없어요.
휴대폰에서도 그냥 돌아갑니다.

## 지금 들어있는 것

| 레벨 | 식당 | 난이도 | 찾을 물건 |
|---|---|---|---|
| 1 | 🍙 김밥천국 | 쉬움 | 접시, 사람, 핸드폰 |
| 2 | 🍕 피자가게 | 보통 | 피자, 햄버거, 게임기, 옷 |
| 3 | 🍣 초밥집 | 어려움 | 숫자 7, 숫자 카드, 유튜버, 핸드폰, 접시 |
| 4 | 🥡 중국집 | 매우 어려움 | 갈비, 햄버거, 사람, 옷, 게임기 |
| 5 | 🎂 생일파티 뷔페 | 최고 | 피자, 갈비, 숫자 7, 숫자 카드, 유튜버, 사람 |

**숨기는 요령**: 목표가 `숫자 7`이면 방해물에 `1️⃣2️⃣3️⃣...`을 잔뜩 깔고,
목표가 `옷`이면 방해물에 `👗👖🧥`을 깔아둡니다. 비슷한 것들 사이에 숨겨야 찾는 맛이 납니다.

## 규칙

- 물건 하나 찾으면 **코인 10개**
- 클리어하면 **보너스 50코인 + 남은 시간 1초당 2코인**
- 엉뚱한 걸 누르면 **시간 3초 깎임**
- 힌트는 **30코인**

## 조카들과 같이 고치는 법

### 1. 새 식당 추가하기 (제일 재밌는 부분)

`index.html`을 열고 `RESTAURANTS` 목록을 찾으세요. 아래 덩어리를 통째로 복사해서
`];` 바로 앞에 붙여넣고 내용만 바꾸면 새 식당이 생깁니다.

```js
{
  id: "chicken",                    // 겹치지 않는 영어 이름
  name: "치킨집",                    // 화면에 보이는 이름
  emoji: "🍗",
  diff: "보통", diffClass: "d2",     // d1~d5 (색깔만 바뀜)
  time: 75,                         // 제한 시간(초)
  boss: "🧑‍🍳",
  bossName: "치킨 사장님",
  quest: "튀기다가 정신없어서 물건을 다 잃어버렸어!",
  praise: "최고다! 치킨 한 마리 서비스!",
  wall: "#ffe6bf", wall2: "#ffd79b", floor: "#c98f5a",   // 벽/바닥 색
  targets: [                        // 찾아야 하는 물건
    { emoji: "🍗", name: "치킨" },
    { emoji: "🥤", name: "콜라" }
  ],
  decoys: ["🍟","🧂","🌶️","🥗"],     // 방해물 (많을수록 어려움)
  clutter: 40                       // 방해물을 몇 개 뿌릴지
},
```

새 식당은 목록 **맨 뒤에** 넣으세요. 앞에 넣으면 해금 순서가 바뀝니다.

### 2. 난이도 조절하기

- 너무 어렵다 → `time` 늘리기, `clutter` 줄이기
- 너무 쉽다 → `clutter` 늘리기, `targets`에 물건 추가, 비슷하게 생긴 `decoys` 추가

### 3. 숫자만 바꿔서 게임 느낌 바꾸기

`index.html` 안에서 이 부분을 찾으세요:

```js
var COIN_PER_FIND = 10;   // 물건 하나 찾을 때 코인
var CLEAR_BONUS   = 50;   // 클리어 보너스
var TIME_BONUS    = 2;    // 남은 1초당 코인
var HINT_COST     = 30;   // 힌트 가격
var WRONG_PENALTY = 3;    // 헛다리 짚으면 깎이는 시간(초)
```

## 다음에 넣어보면 좋을 것 (조카들 숙제)

- [ ] 조카들이 직접 그린 그림을 이모지 대신 넣기
- [ ] 조카 목소리를 녹음해서 사장님 목소리로 넣기
- [ ] 최고 기록(별점) 저장하기
- [ ] 코인으로 살 수 있는 아이템 만들기 (시간 +10초 같은 것)
- [ ] 움직이는 물건 넣기 (도망가는 고양이)

## 기술 메모

- 파일 하나짜리 HTML. 외부 라이브러리 없음, 이미지 파일 없음(전부 이모지), 소리도 코드로 직접 만듦
- 진행 상황은 브라우저의 `localStorage`에 저장됩니다 (타이틀 화면에서 초기화 가능)
- 목표 물건은 항상 맨 위 레이어(z-index 35)에 배치됩니다. 방해물에 완전히 덮여서
  못 누르는 일이 생기면 안 되기 때문입니다

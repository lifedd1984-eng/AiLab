# 🌙 한밤의 식당 대소동

삼촌과 조카들이 함께 만드는 **밤 마을 심부름 게임**입니다.

> 밤 마을을 돌아다닌다 → ❗ 표시가 뜬 식당에 들어가면 사장님이 의뢰를 준다
> → 찾을 물건은 **여러 식당에 흩어져** 있다 → 가게마다 들어가 냉장고·서랍을 뒤진다
> → 다 모으면 🎁 의뢰한 식당으로 돌아가 사장님께 갖다준다 → 코인 + 레벨업

## 어떻게 실행해?

`index.html` 파일을 더블클릭하면 끝입니다. 설치할 것도, 인터넷도 필요 없어요.
휴대폰에서도 그냥 돌아갑니다.

## 어떻게 노는 거야?

1. **밤 마을**을 옆으로 밀어서 둘러봅니다. 식당도 있고 아파트·편의점·문방구도 있어요
2. **❗ 표시가 뜬 식당**에 들어가면 사장님이 나와서 뭘 찾아달라고 부탁해요
3. 찾을 물건은 **한 가게에 다 있지 않습니다.** 마을 곳곳의 식당에 흩어져 있어요
4. 가게 안에서 **냉장고 · 찬장 · 오븐 · 서랍장 · 쓰레기통 · 상자**를 눌러서 열어보세요 (✋ 표시)
5. **테이블 위 · 테이블 밑 · 선반 · 카운터 · 화분 뒤**도 잘 보세요
6. 다 찾으면 **🎁 표시가 뜬 의뢰한 식당**으로 돌아가 갖다줍니다
7. 엉뚱한 걸 누르면 **시간 3초 깎임**

시간은 **의뢰를 받는 순간부터 갖다줄 때까지 계속 흐릅니다.** 가게를 옮겨 다니는
시간도 포함이라 그만큼 넉넉하게 줬어요.

## 의뢰 목록

| 레벨 | 의뢰한 사장님 | 시간 | 물건 | 흩어진 식당 수 |
|---|---|---|---|---|
| 1 | 🍙 김밥 사장님 | 3분 | 3개 (접시, 사람, 핸드폰) | 3곳 |
| 2 | 🍕 피자 사장님 | 4분 | 4개 (피자, 햄버거, 게임기, 옷) | 4곳 |
| 3 | 🍣 초밥 장인 | 5분 | 5개 (숫자 7, 숫자 카드, 유튜버, 핸드폰, 접시) | 5곳 |
| 4 | 🥡 짜장 사장님 | 5분 30초 | 5개 (갈비, 햄버거, 사람, 옷, 게임기) | 5곳 |
| 5 | 🎂 뷔페 지배인 | 7분 | 6개 (피자, 갈비, 숫자 7, 숫자 카드, 유튜버, 사람) | 5곳 |

레벨이 오를수록 물건이 **더 많은 가게에, 더 가구 안쪽 깊이** 숨습니다.

**숨기는 요령**: 목표가 `숫자 7`이면 방해물에 `1️⃣2️⃣3️⃣...`을 잔뜩 깔고,
목표가 `옷`이면 방해물에 `👗👖🧥`을 깔아둡니다. 비슷한 것들 사이에 숨겨야 찾는 맛이 납니다.

## 조카들과 같이 고치는 법

### 1. 새 의뢰 만들기 (제일 쉽고 재밌는 부분)

`QUESTS` 목록 맨 뒤에 붙여넣으세요. `shop` 이 그 물건이 **숨어 있는 식당**입니다.
일부러 여러 식당으로 흩어놓아야 돌아다니는 재미가 생깁니다.

```js
{
  from: "sushi",        // 의뢰한 사장님의 식당
  time: 300,            // 제한 시간(초)
  hideRatio: 0.8,       // 가구 '안'에 숨기는 비율 (1이면 전부 문 열어야 나옴)
  ask: "이것 좀 찾아줘!",
  praise: "고마워! 최고야!",
  items: [
    { emoji: "🍗", name: "치킨", shop: "kimbap" },   // 김밥천국에 숨음
    { emoji: "🥤", name: "콜라", shop: "buffet"  }    // 뷔페에 숨음
  ]
},
```

### 2. 새 식당 추가하기

`SHOPS` 목록에 추가하면 마을 지도에 건물이 생깁니다.

```js
{
  id: "chicken", name: "치킨집", emoji: "🍗",
  boss: "🧑‍🍳", bossName: "치킨 사장님",
  x: 40, w: 12, h: 46,          // 마을에서의 위치·크기 (마을 전체 가로가 100)
  sign: "#ffd166",              // 네온 간판 색
  bw: "#3a3f6e", br: "#2a2e52", // 건물 벽 / 지붕 색
  menu: ["후라이드 18000", "콜라 2000"],
  colors: { wall:"#8a6a45", wood:"#5c3a1c", floor:"#7a5433",
            cab:"#b8ae9c", cabDoor:"#c9c0ac", accent:"#c98a3a" },
  wallProps: ["🍗", "🕐"],       // 벽 액자 / 시계
  decoys: ["🍟","🧂","🌶️","🥗"]  // 그 가게에 굴러다니는 방해물
},
```

`x` 는 다른 건물과 겹치지 않게 정하세요. 지금 쓰는 자리:
아파트 0, 김밥천국 10, 편의점 24, 피자가게 33, 초밥집 47, 문방구 60, 중국집 70, 뷔페 84.

### 3. 가게 안 구조 바꾸기

`LAYOUT` 이 가게 내부 가구 배치입니다. 모든 식당이 이 구조를 같이 씁니다.

```js
{ id:"fridge", type:"door2", kind:"in", x:2, y:24, w:9, h:46, cap:4, name:"냉장고" },
```

- `kind:"in"` → **문을 열어야 보이는 곳** (진짜 숨는 자리)
- `kind:"on"` → 위에 놓여 있는 곳 (선반, 카운터, 테이블 위)
- `kind:"under"` → 밑에 굴러 들어간 곳 (테이블 밑, 화분 뒤)
- `type` → 생김새: `door2`(양문) `door1`(외문) `drawer`(서랍) `lid`(뚜껑)
  `flap`(상자) `shelf` `counter` `table` `under` `plant`
- `cap` → 그 안에 물건을 몇 개까지 넣을지

### 4. 숫자만 바꿔서 느낌 바꾸기

```js
var COIN_PER_FIND = 15;   // 물건 하나 찾을 때 코인
var CLEAR_BONUS   = 60;   // 배달 완료 보너스
var TIME_BONUS    = 1;    // 남은 1초당 코인
var HINT_COST     = 40;   // 힌트 가격
var WRONG_PENALTY = 3;    // 헛다리 짚으면 깎이는 시간(초)
```

## 다음에 넣어보면 좋을 것 (조카들 숙제)

- [ ] 조카들이 직접 그린 그림을 이모지 대신 넣기
- [ ] 조카 목소리를 녹음해서 사장님 목소리로 넣기
- [ ] 식당마다 가구 배치를 다르게 하기 (`LAYOUT`을 식당별로 두기)
- [ ] 마을에 손전등 아이템 넣기 (어두운 구석을 비추면 물건이 보임)
- [ ] 밤 → 새벽으로 하늘색이 점점 변하기 (시간이 줄어드는 게 눈에 보이게)
- [ ] 코인으로 살 수 있는 것 (시간 +30초, 힌트 할인)

## 기술 메모

- 파일 하나짜리 HTML. 외부 라이브러리 없음, 이미지 파일 없음, 소리도 코드로 직접 만듦
- 마을(가로 260%)과 가게 내부(가로 220%) 모두 화면보다 넓어 좌우로 밀어 탐색합니다
- 진행 상황은 브라우저 `localStorage`에 저장 (타이틀 화면에서 초기화 가능)
- 밤 조명: 가게 전체에 어두운 막(`.nightlight`)을 덮고, 천장 전등을 그 **위에**
  `mix-blend-mode: screen` 으로 올려서 빛이 더해지게 했습니다. 덮는 방식으로 하면
  전등 아래가 오히려 더 어두워집니다
- 가로등은 건물을 다 그린 뒤에 세웁니다. 먼저 그리면 건물에 완전히 가려집니다
- 가구(`.furn`)에 `z-index:1`을 줍니다. 없으면 화분 뒤처럼 뒤쪽에 놓인 물건이
  바닥에 가려 눌리지 않습니다
- 문 없는 자리(선반·테이블·카운터)도 물건 담는 칸을 반드시 가구에 붙여야 합니다.
  안 붙이면 그 자리 물건이 화면에 아예 안 나옵니다

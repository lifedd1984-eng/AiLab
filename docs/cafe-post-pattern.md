# 투자 카페/블로그 글쓰기 패턴 (레퍼런스)

출처: 네이버 카페 "투자 이야기(금융)" 게시글 —
「"은퇴 후 커버드콜만 믿어도 될까?" 20년 백테스트로 검증해 봤습니다」
(ETF로노후대비 정회원, 2026-09-03)

---

## 8단 구조

| 순서 | 하는 일 | 원글 예시 |
|---|---|---|
| 1. 제목 = 질문 + 검증 수단 + 기간 | 흔한 믿음을 의문형으로 던지고, 검증 방식과 기간을 숫자로 못박음 | "커버드콜만 믿어도 될까?" 20년 백테스트로 검증 |
| 2. 기존 것의 구멍 지적 | 이 글이 왜 필요한지, 왜 남들은 못 보여주는지 | "대부분 커버드콜 ETF는 상장한 지 얼마 안 돼서 실제 운용 기간이 짧다" |
| 3. 독자의 불안을 정확히 지목 | 일반론이 아니라 "이 사람 얘기"로 좁힘 | "은퇴 후 현금흐름이 절실한 분들이 정말 이거 하나만 믿어도 되나" |
| 4. 도구를 보여줌 | 의견이 아니라 실제로 만든 시뮬레이터·도구를 제시 (핵심) | 백테스트 시뮬레이터 화면 캡처 |
| 5. 조건을 스펙처럼 명시 | 시점·금액·기간·방식을 표로 못박아 신뢰도를 올림 | "2007~2008년 직전, 3억 원, 20년, 전액 생활비 인출" |
| 6. 질문 던지고 → 데이터로 답 | 서스펜스를 만들고 그래프·표로 해소 | "원금이 녹아내리지 않고 살아남았을까요?" → 자산곡선 |
| 7. 숫자를 한 문장으로 요약 | 표만 던지지 않고 반드시 결론 문장을 붙임 | "정률 인출이 장기 복리에서 커버드콜보다 우수" |
| 8. 함정 파고들기 + 반박 선점 + 면책 | 더 깊은 통찰 + 예상 반론에 먼저 답 + "저는 안 판다"는 면책 | ROC 함정 설명, "20년치를 어떻게 검증했나" 방법론 공개, "저는 지수투자 함" |

## 왜 통하는가

**핵심은 4번.** 의견·요약이 아니라 **직접 만든 도구**로 검증했다는 것이 글 전체의 신뢰도를 만든다.
동시에 이게 실제 유입 장치다 — 그래프마다 도구 링크를 출처로 박아둔다. **글은 미끼, 도구가 목적지.**

**8번 면책도 계산된 장치.** "저는 이거 안 하고 저거 합니다"라고 먼저 밝히면, 무언가를 팔려는 게 아니라는 게
증명되면서 나머지 주장 전체의 신뢰도가 같이 올라간다.

## ELS 레이더 적용 초안

ELS 레이더는 이미 도구(69,903건 전수 판정 데이터)를 갖고 있어서 이 패턴에 특히 잘 맞는다.

> **"낙인 45%면 정말 안전한 걸까? 10년, 69,903건 전수 판정해봤습니다"**

| 단계 | 적용 |
|---|---|
| 기존 구멍 | 낙인 %만 보고 고르는 사람은 많은데, 그게 실제로 안전을 보장하는지 검증한 사람은 없다 |
| 도구 제시 | ELS 레이더 화면 캡처 |
| 조건 명시 | 2016~2025년, 국내 공모 발행 전체, 조기상환·낙인·손실 결과 전부 판정 |
| 질문→데이터 | 낙인 45% 상품 중 실제 손실 난 비율은 몇 %였을까요? → 실제 수치 |
| 함정 파고들기 | 손실은 낙인 %가 아니라 발행 시점 때문이었다 (기존 시리즈 1편 인사이트와 연결) |
| 면책 | 저도 실제 투자 중이고, 매수 권유가 아니라 데이터 공유입니다 |

## 체크리스트 (다음 글 쓰기 전에)

- [ ] 제목에 "질문형 믿음" + "검증 수단" + "숫자(기간/건수)"가 들어갔는가
- [ ] "왜 이 정보가 지금까지 없었는지"를 짚었는가
- [ ] 도구(스크린샷·데이터·계산기)를 실제로 보여주는가, 말로만 하는가
- [ ] 조건을 표/스펙으로 명시했는가
- [ ] 질문 → 데이터 공개 순서로 서스펜스를 만들었는가
- [ ] 데이터 뒤에 한 문장 결론이 붙어 있는가
- [ ] 예상 반론(신뢰도 의심)에 먼저 답했는가
- [ ] "저는 안 팝니다" 류의 면책·자기 포지션이 있는가
- [ ] 도구로 이어지는 출처 링크가 붙어 있는가

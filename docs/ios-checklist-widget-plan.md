# 체크리스트 앱 + 홈 화면 위젯 기획안

문서 버전: v1.0 · 작성일: 2026-08-09 · 대상 플랫폼: iOS (iPhone 우선)

---

## 1. 한 줄 요약

할 일과 장 볼 것을 한 줄씩 적고, 끝나면 체크해서 지우는 **아주 단순한 체크리스트 앱**.
핵심 차별점은 **앱을 열지 않고 홈 화면 위젯에서 바로 체크**할 수 있다는 것.

---

## 2. 배경과 문제 정의

- 기존 할 일 앱은 프로젝트, 태그, 반복, 협업 등 기능이 너무 많아 "우유 사기" 한 줄 적기에 부담이 크다.
- 정작 필요한 순간(마트 계산대 앞, 집 나서기 직전)에는 **앱을 여는 3초조차 귀찮다.**
- 홈 화면에서 목록이 항상 보이고, **탭 한 번으로 체크**되면 그 마찰이 사라진다.

**해결하려는 것**: "적는 마찰"과 "확인/완료 마찰"을 동시에 0에 가깝게 만든다.

---

## 3. 목표 / 하지 않을 것

### 목표 (MVP)
1. 항목을 3초 안에 추가할 수 있다.
2. 홈 화면 위젯에서 앱 실행 없이 체크/해제할 수 있다.
3. 체크한 항목은 목록에서 사라지고, 되돌릴 수 있다.

### 이번에 하지 않을 것 (명시적 제외)
- 계정/로그인, 서버, 공유·협업
- 반복 일정, 알림, 위치 기반 리마인더
- 태그·우선순위·정렬 규칙 등 고급 분류
- Android / 웹 / Mac 버전

> 뺀 기능은 "안 만든다"가 아니라 **v2 이후로 미룬다**는 뜻. 4장 로드맵 참고.

---

## 4. 타깃 사용자와 사용 시나리오

**주 사용자**: 복잡한 생산성 앱에 지친 일반 사용자. 하루 3~10개 항목 수준.

| # | 상황 | 흐름 |
|---|------|------|
| S1 | 자기 전 내일 할 일 정리 | 앱 열기 → 3~4개 입력 → 종료 |
| S2 | 마트에서 장보기 | 홈 화면 위젯 보면서 담을 때마다 위젯에서 바로 체크 |
| S3 | 외출 직전 확인 | 홈 화면 훑기만 하고 앱 실행 안 함 |
| S4 | 잘못 체크함 | 앱에서 "완료됨" 열어 되돌리기 |

가장 중요한 건 **S2** — 이 앱의 존재 이유다.

## 5. 위젯 크기: 요청사항과 iOS 제약

### 요청
"앱 아이콘 4~5개 폭, 1행짜리 긴 막대 (1×5)"

### 제약 (사실 확인 필요한 부분)
iOS 위젯은 개발자가 픽셀 크기를 정할 수 없다. 시스템이 정한 규격 중에서만 고른다.

| 규격 | 홈 화면 점유 | 비고 |
|------|--------------|------|
| `systemSmall` | 2열 × 2행 | 정사각형 |
| **`systemMedium`** | **4열 × 2행** | **가로로 긴 막대 — 요청에 가장 근접** |
| `systemLarge` | 4열 × 4행 | 정사각형에 가까움 |
| `systemExtraLarge` | iPad 전용 | iPhone 미지원 |

- iPhone 홈 화면은 **가로 4열**이라 "5열 폭"은 물리적으로 불가능하다.
- **1행 높이 위젯은 iOS에 존재하지 않는다.** 최소 높이가 2행이다.

### 결론 및 대안
**`systemMedium`(4×2)을 기본 위젯으로 채택.** 화면에서 가로로 길쭉한 막대로 보이며, 의도한 "긴 형태"에 가장 가깝다.

진짜 한 줄짜리가 필요하다면 대안은 두 가지다.

- **잠금화면 위젯 (`accessoryInline`)** — 시계 위 한 줄에 "🛒 우유 외 3개" 형태로 표시. 실제로 1행이지만 홈 화면이 아니라 잠금화면이고, 체크는 불가(표시 전용).
- **`systemSmall` 2개 나란히 배치** — 폭 4열을 채우면서 시각적으로는 다른 느낌. 권장하지 않음.

→ **홈 화면 4×2 중형을 메인으로 하고, 잠금화면 인라인 위젯을 보조로 함께 제공**하는 것을 권장한다.

## 6. 기능 명세

### 6.1 MVP (v1.0)

| ID | 기능 | 상세 |
|----|------|------|
| F1 | 항목 추가 | 상단 입력창에 텍스트 입력 후 완료. 입력창은 앱 진입 시 자동 포커스, 저장 후에도 포커스 유지해 연속 입력 가능 |
| F2 | 항목 체크 | 탭하면 체크 → 0.4초 후 목록에서 사라짐(취소 여유) |
| F3 | 되돌리기 | 사라진 직후 하단 "실행 취소" 스낵바 5초 노출 |
| F4 | 완료 목록 | 별도 화면에서 최근 7일 완료 항목 확인 및 복원 |
| F5 | 항목 수정/삭제 | 스와이프로 삭제, 탭 유지(길게)로 텍스트 수정 |
| F6 | 순서 변경 | 길게 눌러 드래그 |
| F7 | **위젯 표시** | 미완료 항목을 위에서부터 표시 |
| F8 | **위젯 내 체크** | 위젯의 체크박스를 직접 탭해 완료 처리 (앱 실행 없음) |
| F9 | 위젯 → 앱 이동 | 위젯의 텍스트 영역 탭 시 앱 열기 |

### 6.2 v1.1 (출시 직후)
- 목록 분리: "할 일" / "장보기" 2개 리스트, 위젯에서 어느 리스트를 볼지 선택
- 다크모드 전용 색상 튜닝, 위젯 테마 3종
- 잠금화면 위젯 (`accessoryRectangular`, `accessoryInline`)

### 6.3 v2 이후 후보
- iCloud 동기화(기기 간), Apple Watch 앱
- 마감일 + 알림
- Siri / 단축어 연동("클로드야, 장보기에 우유 추가")
- Control Center 컨트롤(빠른 추가)

## 7. 화면 설계

### 7.1 메인 화면

```
┌──────────────────────────────┐
│  오늘                    ⋯   │   ← 타이틀 / 설정
│                              │
│  ┌────────────────────────┐  │
│  │ + 새 항목 입력…        │  │   ← 항상 상단 고정, 자동 포커스
│  └────────────────────────┘  │
│                              │
│  ○  우유 사기                │
│  ○  세탁물 찾기              │   ← 탭 = 체크, 스와이프 = 삭제
│  ○  전기요금 납부            │      길게 = 순서 변경
│  ○  병원 예약 전화           │
│                              │
│  ─────────────────────────   │
│  완료됨 3개                ›  │   ← 접힌 상태, 탭하면 펼침
└──────────────────────────────┘
```

### 7.2 홈 화면 위젯 (`systemMedium`, 4열 × 2행)

```
┌───────────────────────────────────────────────┐
│  ✓ 오늘 할 일                          4개    │
│  ○ 우유 사기                                  │
│  ○ 세탁물 찾기                                │
│  ○ 전기요금 납부                     + 1개 더 │
└───────────────────────────────────────────────┘
     ↑ 이 원을 직접 탭 = 즉시 완료 처리
```

- **표시 항목 수**: 3개 + 남은 개수 요약. (가독성 있는 글자 크기 기준 실측 한계)
- **빈 상태**: "할 일이 없네요 ✨ 탭해서 추가하기"
- **탭 영역 구분**: 왼쪽 체크박스(28pt) = 완료 처리 / 나머지 = 앱 열기

### 7.3 잠금화면 위젯 (`accessoryInline`, 보조)

```
🛒 우유 사기 외 3개
```

## 8. 데이터 모델

```swift
@Model
final class ChecklistItem {
    var id: UUID
    var title: String
    var isDone: Bool
    var createdAt: Date
    var completedAt: Date?
    var sortOrder: Int
    var listKind: ListKind   // .todo / .shopping (v1.1부터 실제 사용)
}
```

- 저장소: **SwiftData**, App Group 컨테이너에 배치
- 앱과 위젯이 **동일한 저장소를 공유**해야 하므로 App Group 설정이 필수
  (`group.com.<팀>.checklist`)
- 완료 후 7일 지난 항목은 앱 실행 시 자동 정리

## 9. 기술 설계

| 영역 | 선택 | 이유 |
|------|------|------|
| 최소 지원 버전 | **iOS 17.0+** | 위젯 내 상호작용(체크)이 iOS 17부터 가능. 이게 핵심 기능이라 타협 불가 |
| UI | SwiftUI | 앱/위젯 뷰 코드 공유 |
| 위젯 | WidgetKit | |
| 위젯 상호작용 | **AppIntent** (`ToggleItemIntent`) | 위젯 버튼 → Intent 실행 → 저장소 수정 → 타임라인 갱신 |
| 저장소 | SwiftData + App Group | 서버 없이 앱↔위젯 공유 |
| 동기화 | 없음 (v1.0) | 로컬 전용. v2에서 CloudKit |

### 위젯 갱신 정책
- 앱에서 항목 변경 시 `WidgetCenter.shared.reloadAllTimelines()` 즉시 호출
- 위젯에서 체크 시 Intent 내부에서 저장 후 자동 갱신
- 시간 기반 갱신은 하루 1회(자정) — 시스템 갱신 예산 절약

### 프로젝트 구조
```
Checklist/
├── ChecklistApp/          # 메인 앱 타깃
├── ChecklistWidget/       # 위젯 익스텐션 타깃
└── ChecklistKit/          # 공유 프레임워크
    ├── Models/            # ChecklistItem, ListKind
    ├── Store/             # SwiftData 컨테이너 (App Group)
    └── Intents/           # ToggleItemIntent
```

## 10. 비기능 요구사항

- 앱 아이콘 탭 → 입력 가능 상태까지 **1초 이내**
- 위젯 체크 탭 → 화면 반영까지 **1초 이내**
- 네트워크 권한 불필요, 수집 데이터 없음 (App Store 개인정보 라벨 "데이터 미수집")
- 다이나믹 타입(글자 크기 조절) 및 VoiceOver 대응
- 다크모드 지원

## 12. 리스크

| 리스크 | 영향 | 대응 |
|--------|------|------|
| "1×5" 위젯 불가 | 기대와 다른 모양 | 4×2 중형으로 확정 (5장). 프로토타입 먼저 홈 화면에 올려서 확인 |
| 위젯 갱신 지연 | 체크가 늦게 반영되어 답답함 | Intent 기반 즉시 갱신 사용. 시스템 예산 초과 방지 위해 시간 기반 갱신 최소화 |
| 위젯에 3개만 표시 | 장보기 목록이 길면 부족 | 남은 개수 표시 + `systemLarge`(최대 8개) 옵션 병행 제공 |
| iOS 17 미만 사용자 배제 | 잠재 사용자 일부 손실 | 핵심 기능 요건. 현재 iOS 17+ 점유율 고려 시 수용 가능 |
| App Group 설정 누락 | 위젯이 빈 목록만 표시 | 1단계에서 가장 먼저 검증 |

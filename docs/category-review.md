## 2. 문제는 두 개입니다

### 문제 1 — 이름이 깁니다 (지적하신 부분)

네이버 블로그 사이드바 폭은 약 150px입니다. 하위 카테고리는 들여쓰기 때문에
**실제 쓸 수 있는 폭이 7~8자**, 상위는 9~10자 정도입니다.

현재 **11자 이상이 8개**로, 화면에서 2~3줄로 접혀 목록이 읽기 어렵습니다.
가장 심한 것은 `투자하면서 하지 않는 것들`(13자), `사용자 경험과 수정 기록`(12자).

### 문제 2 — 카테고리가 글보다 많습니다 (더 심각)

| | 개수 |
|---|---|
| 상위 카테고리 | 6 |
| 하위 카테고리 | 19 |
| 보관함 | 1 |
| **합계** | **26** |
| **전체 글** | **25** |

**카테고리 26개에 글 25개.** 평균 1개 미만이라 대부분이 빈 칸입니다.
방문자에게는 "만들어두고 안 쓰는 블로그"로 읽히고, 검색 유입자가 관련 글을
더 찾아볼 동선도 끊깁니다.

두 문제는 **같은 방법으로 함께 해결됩니다**: 하위에서 상위 이름을 반복하지 않고,
글이 없는 하위를 상위로 흡수하는 것입니다.

## 3. 이름 수정안 (구조 유지, 이름만 축약)

기준: **하위 6자 이내, 상위 5자 이내**
핵심 원칙: **하위 카테고리에서 상위 이름을 반복하지 않습니다.** 들여쓰기가 이미
소속을 보여주므로 `ELS 처음 공부하기`는 `기초`만으로 충분합니다.

### 판단이 필요한 3건

**`연말정산과 종합소득세` → `연말정산`**
줄이면 종합소득세가 이름에서 빠집니다. 대안은 `연말정산·종소세`(7자)인데
들여쓰기 때문에 여전히 접힐 수 있습니다. 검색 유입은 `연말정산`이 압도적으로
크므로 **카테고리명은 `연말정산`으로 하고 종합소득세는 글 제목과 태그로 잡는 것**을 권합니다.

**`ELS 레이더 제작기` ↔ `서비스를 만드는 과정` 중복**
같은 성격입니다. `제작기` 하나로 합치고 ELS 레이더 관련 제작 글은 그쪽으로 옮기는 것을 권합니다.

**`읽고 배운것 > 서비스` ↔ `제작기` 중복**
"읽고 배운 것" 아래의 `서비스`가 무엇을 담는지 불명확하고 `제작기`와 겹칩니다.
글이 있으면 성격에 따라 재배치, 없으면 삭제.

## 4. 구조 통합안 (권장)

이름만 줄여도 읽기는 나아지지만, **빈 카테고리 문제는 남습니다.**
26개 → **15개**로 줄이는 안입니다.

```
절세
├ 생활 절세
└ 연말정산
ELS
├ 기초
└ 데이터
제작기
├ 기획
├ 개선 기록
└ 운영
투자 원칙
├ 위험 먼저
├ 숫자 읽기
└ 장기 투자
돈과 삶
├ 일상
└ 쓰는 기준
읽은 것
```

상위 6 + 하위 9 = **15개**. 모든 이름이 사이드바에서 한 줄에 들어갑니다.

### 통합 내역

| 없앤 것 | 어디로 |
|---|---|
| ELS 레이더 제작기 | → 제작기 |
| 투자하면서 하지 않는 것들 | → 위험 먼저 (같은 주제) |
| 여행자의 길 | → 일상 |
| 책 / 서비스 / 사람과 시장 | → 읽은 것 (하위 없이 단일 카테고리) |

**전제:** 카테고리별 실제 글 수를 모르는 상태의 제안입니다.
통합 대상에 글이 여러 편 있으면 그 하위는 살려야 합니다.
관리 화면의 카테고리별 글 수를 주시면 확정안으로 다듬겠습니다.

### 하위 카테고리 기준

앞으로 하위를 만들 때는 **글 3편 이상 확보된 주제만** 분리하는 것을 권합니다.
지금은 6개 상위만으로도 25편을 충분히 나눌 수 있습니다.

기존 `ELS RADAR` 배너를 블로그명 **「돈의 구조를 읽고 만드는 삶」** 기준으로
다시 만든 것입니다 (`blog-plan.md` §2 문제 2의 **안 A**).

### 유지한 것

- 남색·파랑·금색 팔레트 — 기존 배너·프로필 이미지와 동일
- 레이더 호(arc) — 이전 `ELS RADAR` 배너와의 연속성
- 금빛 동전이 파란 구조를 통과하는 모티프 — 프로필 이미지 개념과 동일
- 지표 3개를 얇은 구분선으로 나눈 배치 — 기존 배너 형식

### 바꾼 것

| 항목 | 기존 | 신규 |
|---|---|---|
| 주제목 | ELS, 데이터로 읽습니다 | 돈의 **구조**를 읽고 만드는 삶 |
| 정체성 | ELS 단일 서비스 | 블로그 전체 (읽고 · 만들고 · 기록) |
| 지표 | 69,903건 / 2016–2025 / 매주 갱신 | 69,903건 / 2개 / 매주 |
| 지표 성격 | 전부 ELS 데이터 | 데이터 + 만든 서비스 + 지속성 |

지표를 `69,903건`(읽기) · `2개`(만들기) · `매주`(기록)로 바꿔서
블로그명의 세 동작과 대응시켰습니다. 69,903건은 신뢰도 자산이라 그대로 살렸습니다.

### 모티프를 바꾼 이유

초안은 우상향 곡선이었는데 폐기했습니다. `위험을 먼저 보는 습관`,
`감이 아니라 숫자`를 내세우는 블로그에서 우상향 그래프는 수익 약속으로 읽혀
메시지와 충돌합니다. 대신 **분포형 히스토그램**(가운데가 높고 양쪽이 낮은 형태)으로
바꿨습니다. 우상향을 암시하지 않으면서 "전수 판정한 데이터"를 나타냅니다.

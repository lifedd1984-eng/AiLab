## 3. 카테고리 (결정 필요)

원안 6개:

1. 돈의 구조
2. ELS를 읽는 법
3. 절세를 만드는 법
4. 서비스를 만드는 기록
5. 투자하며 배운 것
6. 일상의 생각

**검토 의견:** 개설 시점 콘텐츠가 5편인데 카테고리가 6개면 대부분이 빈 칸으로 보입니다.
개설은 4개로 시작하고 글이 쌓이면 분리하는 편이 낫습니다.

- 개설 시: `돈의 구조` / `ELS를 읽는 법` / `절세를 만드는 법` / `만들면서 배운 것`
- 나중 분리: `투자하며 배운 것`, `서비스를 만드는 기록`, `일상의 생각`

`일상의 생각`은 금융 신뢰도가 자리를 잡은 뒤 여는 편이 안전합니다.

## 4. 공통 글쓰기 양식 (7단)

1. 궁금증이나 실제 상황
2. 쉬운 비유
3. 핵심 개념
4. 사례와 그림
5. 개인의 생각
6. 한 줄 정리
7. 관련 서비스 안내

## 5. 첫 게시물 5편

1. 돈의 구조를 읽고 만드는 삶을 시작합니다
2. ELS는 어떤 방식으로 돈을 버는 상품일까
3. 고향사랑기부제, 기부하면서 세금도 줄이는 방법
4. 좋은 투자는 높은 수익률보다 구조를 먼저 본다
5. 두 개의 금융 서비스를 직접 만들게 된 이유

## 6. 리스크 및 확인 필요 사항

### 중복 콘텐츠 (가장 큰 리스크)

`elsrader.site`에 이미 30편이 게시되어 있고 사이트맵까지 등록된 상태입니다.
같은 내용을 네이버 블로그에 올리면 두 곳이 검색에서 서로 경쟁합니다.
네이버 블로그는 canonical 태그를 지원하지 않아 원문 지정이 불가능합니다.

권장: 블로그에는 **개인 경험과 해석을 더한 축약본**을 올리고, 상세 데이터와 표는
`elsrader.site` 원문으로 링크. 즉 3-3은 "재편집"이 아니라 "다른 글 쓰기"로 접근.

### 이미지 생성 사용량

대화 시점에 이미지 생성 제한이 걸렸고, 사용량 리셋은 9월 7일 오전 11:29입니다.
1-3(대문 이미지)과 2-2(썸네일 틀)가 여기에 묶여 있습니다.

### 자동화 불가 영역

네이버 블로그는 공개 API로 글 작성·카테고리 설정을 자동화할 수 없습니다.
1-4, 4-1의 실제 적용은 수동 작업입니다. 코드로 처리 가능한 범위는 원고 생성,
이미지 제작, 성과 관리표 정도입니다.

### 블로그 실태 미확인

주소(`m.blog.naver.com/elsrader`)는 확인되었으나 현재 전체 카테고리, 게시물 목록,
관리 설정은 미확인 상태입니다. 1-4를 시작하기 전에 현황 파악이 필요합니다.

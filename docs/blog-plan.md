## 2. 새로 드러난 문제 3가지

계획을 다시 짜야 하는 이유입니다. 신규 글 발행보다 이것들이 먼저입니다.

### 문제 1 — 검색 색인이 거의 안 되어 있음 (가장 시급)

글이 **25개**인데 네이버 웹문서 검색에 색인된 것은 **2건**뿐입니다.
23개가 검색에 걸리지 않습니다.

색인된 2건은 둘 다 2008년 투자 서적 요약글입니다.

| 제목 | 주소 | 작성일 |
|---|---|---|
| The successful INVESTOR | `/elsrader/80051860264` | 2008-05-16 |
| 주식천재가 된 홍대리 | `/elsrader/80049807233` | 2008년 상반기 추정 |

즉 **2008년 글은 색인되고 그 이후 글은 색인이 안 된 상태**입니다.
새 글을 몇 편 더 쓰는 것으로는 해결되지 않습니다. 원인 진단이 먼저입니다.

확인해야 할 것:
- 블로그 관리 → **검색 엔진 최적화(SEO) / 검색 결과 노출 허용** 설정이 켜져 있는지
- 개별 글의 **검색 허용** 설정
- 네이버 서치어드바이저에 블로그가 등록되어 있는지
- 25개 중 공유·스크랩 글 비중 (스크랩 글은 원본이 우선되어 색인에서 밀림)
- 저품질 판정 여부 (블로그명으로 검색해 자기 블로그가 나오는지)

### 문제 2 — 정체성이 두 갈래로 갈려 있음

| 위치 | 표현하는 정체성 |
|---|---|
| 블로그명 | 「돈의 구조를 읽고 만드는 삶」 — 넓은 개인 기록 |
| 대문 배너 | `ELS RADAR` / "ELS, 데이터로 읽습니다" — **ELS 단일 서비스 소개** |
| 프로필 소개 | "복잡한 돈을 쉽게 풀고, 직접 서비스로 만듭니다" — 제작자 |
| 카테고리 | 절세 + ELS 레이더 + 투자철학 — 다주제 |

배너는 ELS 서비스 랜딩페이지처럼 읽히는데, 블로그명과 카테고리는 절세·투자철학까지
포괄합니다. 방문자가 첫 화면에서 "ELS 데이터 서비스 소개 페이지"로 인식하면
절세·투자철학 글은 발견되지 않습니다.

**결정 필요:** 어느 쪽을 블로그의 얼굴로 삼을지.

- **안 A — 배너를 블로그명에 맞춘다**: 배너 문구를 「돈의 구조를 읽고 만드는 삶」 기준으로
  다시 쓰고, ELS RADAR 배너는 `ELS 레이더` 카테고리 상단이나 별도 위젯으로 내림.
  다주제 개인 블로그로 일관됨.
- **안 B — 블로그명을 배너에 맞춘다**: ELS 데이터 전문 블로그로 좁히고,
  절세·투자철학은 곁가지로 둠. 전문성은 뾰족해지지만 원래 기획한 다섯 축이 무너짐.

배너 완성도가 높아 아깝지만, 기획 의도(절세·ELS·투자철학·서비스·일상)를 따르면 **안 A**입니다.

### 문제 3 — 최상단 공지가 남의 글 공유

첫 화면 최상단이 **「[공유] [본공지]부(富)동산 오마카세 '블독'편」**(2023-04-27)입니다.
부동산 주제의 타 블로그 스크랩이라, 바로 위 `ELS RADAR` 배너와 충돌합니다.
방문자가 보는 첫 콘텐츠이므로 교체 우선순위가 높습니다.

교체안: 「돈의 구조를 읽고 만드는 삶을 시작합니다」 공지 글 (원 계획 §5-1)

## 3. 남은 작업 (재정렬)

**1개는 부분 완료**(프로필 소개문)입니다. 나머지를 실제 상태에 맞춰 재배치했습니다.

### 0단계 — 진단·결정 (여기부터)

| # | 작업 | 성격 |
|---|---|---|
| 0-1 | **검색 노출 설정 점검** — 관리 화면에서 SEO·검색 허용 설정 확인 | 조사 |
| 0-2 | **기존 25개 글 목록화** — 제목·카테고리·작성일·공유글 여부·색인 여부 | 조사 |
| 0-3 | **정체성 방향 결정** (안 A / 안 B) | 결정 |

## 6. 중복 콘텐츠 리스크

`elsrader.site`에 이미 30편이 게시되고 사이트맵까지 등록된 상태입니다.
같은 내용을 블로그에 올리면 두 곳이 검색에서 경쟁하고, 네이버 블로그는
canonical 태그를 지원하지 않아 원문 지정이 불가능합니다.

배너가 "10년 공모 발행분을 전수 판정한 기록을 **연재**합니다"라고 이미 약속하고 있어
30편 블로그화는 사실상 확정 사항입니다. 그래서 방식이 중요합니다.

권장: 블로그에는 **개인 경험과 해석을 더한 축약본**을 쓰고 상세 데이터·표는
`elsrader.site` 원문으로 링크. "재편집"이 아니라 "다른 글 쓰기"로 접근.
서비스 유입 동선도 이 방식이 유리합니다.

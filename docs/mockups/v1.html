기획안 v2.0 §7 화면 설계를 그대로 옮긴 인터랙티브 목업입니다. 아래 세 화면(중형 위젯 · 대형 위젯 · 앱)은 하나의 저장소를 공유합니다 — 위젯에서 체크하면 앱 목록에서도 사라지는 App Group 동작의 시뮬레이션입니다.

3. 앱 메인 화면 (앱은 이 한 화면이 전부)

앱은 "입력기" 역할에 집중합니다 — 상단 고정 입력창에서 연속 입력, 목록 관리, 잘못 체크한 항목 복구.

◯ 체크 — 취소선 0.4초 후 "완료됨"으로 이동. 0.4초 안에 다시 누르면 취소. 하단 스낵바에서 5초간 실행 취소 가능.

4

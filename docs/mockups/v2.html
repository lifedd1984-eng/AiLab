피드백 3가지를 반영한 개정 목업입니다. 이전과 같이 위젯·앱이 저장소를 공유하며, 모두 직접 눌러볼 수 있습니다.

① 대분류 카테고리 — "살 것" · "할 것", 상단에서 추가 ② 체크해도 사라지지 않음 — 줄긋기 유지 ③ 완료한 목록 히스토리 🕘

1. 홈 화면 — 중형 위젯 (4×2)

위젯 상단에 카테고리 칩이 나란히 표시되고, 칩을 탭하면 앱을 열지 않고 위젯 안에서 해당 카테고리 목록으로 전환됩니다 (iOS 17 위젯 버튼).

2

◯ 체크 → 줄긋기 유지 — 항목이 사라지지 않고 취소선 상태로 남습니다. 다시 탭하면 체크 해제(실행 취소).

3

칩의 숫자는 체크 안 된 항목만 셉니다. 칩이 많아 다 안 보이면 표시 우선순위는 최근 사용 순(칩 행은 1줄 고정).

4

2. 앱 메인 화면 — 카테고리 칩 + 목록 + 히스토리

완료한 목록

1

카테고리 칩 — 탭으로 전환, 숫자는 남은 항목 수. ＋ 추가를 누르면 이름·아이콘을 정해 새 대분류를 만듭니다. 삭제·이름 변경은 칩 길게 누르기(목업 생략).

2

체크 → 줄긋기로 그 자리에 유지. 다시 탭하면 해제. 별도 실행 취소 스낵바가 필요 없어졌습니다.

3

"체크된 N개 정리" — 줄 그어진 항목이 쌓이면 이 버튼으로 목록에서 치웁니다. 치워진 항목은 삭제가 아니라 히스토리로 이동 — 언제든 다시 볼 수 있습니다.

4

🕘 완료한 목록 — 날짜별로 "언제, 어떤 카테고리에서, 뭘 완료했는지"가 쌓입니다. "되돌리기"로 목록에 복원.

3. 대형 위젯 · 다크 모드

대형(4×4)은 같은 카테고리를 8행으로. 다크 모드는 시스템 설정을 따릅니다. 모두 라이브 데이터 공유.

대형(4×4) — 8행 + "+N개 더".
중형 다크 모드 — 같은 데이터.

# 다른 카페용 글 — ELS 175개 관리 도구 소개 (초안, 대기 중)

- 상태: **대기 — 사용자 확인 필요** (아래 "막힌 것" 참고, 확인 전 게시 금지)
- 성격: 카페 1·2편과 다른 카페용. 같은 핵심 통찰(낙인보다 시간 분산)을 다른 각도(개인 노하우 → 실제 대시보드 화면 공개)로 재구성
- 근거 화면: 사용자가 제공한 ELS 레이더 실제 스크린샷 4장 중 3장 사용
  1. 랜딩 히어로 (베타 배지 + CTA 버튼) — **미사용 권장**, 광고성으로 보여 카페 규정(홍보 금지) 저촉 위험
  2. 주간 청약 스크리닝 화면 — 사용
  3. 내 포트폴리오 화면 — 사용 (금액 마스킹 필요)
  4. 상환 캘린더 화면 — 사용

## 막힌 것 — 게시 전 반드시 처리

1. **총 투자금액 마스킹 안 됨.** `내 포트폴리오` 화면의 "1,999,540,000원"이 그대로 노출된 스크린샷을 아직 받지 못함. 사용자가 로컬에서 크롭/모자이크 처리한 이미지를 다시 보내주면 최종 게시 가능.
   - 같은 화면의 "예상 세전수익 +226,265,470원"도 절대금액이라 함께 가리는 것을 권장. 옆의 "+11.32%" 비율 표시로 대체 가능.
2. **스크린샷 3장의 최종 삽입 파일**이 아직 이 리포지터리에 없음. 마스킹 완료된 이미지를 받으면 `docs/assets/`에 추가하고 이 파일의 `[스크린샷 삽입 — ...]` 표시를 실제 이미지 참조로 교체할 것.
3. **카페 선정 미정.** 어느 카페에 올릴지에 따라 도입부 톤(재테크 초보 / 전문 트레이더 / 은퇴 준비)을 한 번 더 조정 필요.

# ELS 175개 들고 있으면, 사람이 관리가 안 됩니다

지난 글에서 나눠서 담으라고 말씀드렸었는데요, 저도 그 말대로 몇 년을 하다 보니 지금 보유 중인 ELS가 **175건**이 됐습니다.

처음엔 엑셀로 관리했는데, 100건 넘어가니까 한계가 오더라고요. 어떤 게 조기상환 평가일이 다가오는지, 어디에 몰려 있는지, 이번 달에 뭐가 들어오는지를 사람 눈으로 따라가는 게 안 됐습니다. 그래서 그냥 직접 도구를 만들어버렸습니다.

## 매주 쏟아지는 물량부터 걸러야 해요

일단 매주 새로 청약 들어오는 ELS만 해도 200건이 넘습니다.

> **[스크린샷 삽입 — 주간 청약 스크리닝 화면]**
> *이번 주 청약 마감 상품 221건, 낙인대별(25/30/35/40)로 최고 수익 상품 자동 정렬*

이걸 낙인 기준으로 25/30/35/40 구간별로 나눠서, 각 구간 안에서 수익률 상위 상품만 자동으로 걸러줍니다. 지난 글에서 말씀드렸던 "쿠폰 유독 높으면 의심하라"는 것도, 이렇게 같은 낙인 구간 안에서 나란히 놓고 보면 뭐가 비정상적으로 튀는지 한눈에 보여요.

## 175건 쌓이니까 사람이 못 보던 게 보이더라고요

포트폴리오 화면은 이렇게 생겼습니다.

> **[스크린샷 삽입 — 내 포트폴리오 화면, 총 투자금액은 크롭 또는 모자이크]**
> *보유 상품 175건 (종목형 136 · 지수형 43), 예상 세전수익률 +11.32%, 예상 손실율 0.45%*

숫자만 보면 괜찮아 보이는데, 진짜 쓸모는 아래 "AI 현황 코멘트"였습니다.

> **기초자산 집중도 — Micron 39%** (분산 점검 기준 30%보다 9%p 높음)
> **청약 시기 집중도 — 7.6~7.12 구간 17%** (기준 15%보다 2%p 높음)

이거 보고 좀 놀랐습니다. 저는 나름 분산해서 담고 있다고 생각했는데, 특정 종목이랑 특정 주에 저도 모르게 쏠려 있더라고요. 175건이나 되니까 이런 게 사람 눈으로는 절대 안 잡힙니다.

지난 글에서 "시간 분산이 낙인보다 중요하다"고 말씀드렸잖아요. 근데 말로는 쉬운데, 실제로 100건 넘게 쌓이면 내가 분산을 잘하고 있는지조차 스스로 확인이 안 됩니다. 그래서 이런 게 자동으로 잡아주지 않으면 모르고 지나가요.

## 상환도 캘린더로 안 보면 놓칩니다

> **[스크린샷 삽입 — 상환 캘린더 화면]**
> *이번 달 조기상환 평가 19건, 상환 완료 1건. 조기상환 성공/실패가 날짜별로 표시*

여기서 하나 짚고 싶은 게, 캘린더에 **"1차 조기상환 실패"**라고 표시된 게 있어요. 이거 보고 놀라실 필요 없습니다. 지난 글에서 말씀드렸듯이 1차에서 안 됐다고 손실이 아니라, 다음 평가일로 그냥 넘어가는 것뿐이에요. 오히려 이렇게 눈에 보이니까 "아 이건 낙인 터진 게 아니라 그냥 다음 차수로 넘어간 거구나"를 헷갈리지 않고 구분하게 됐습니다.

## 정리하면

낙인 잘 보고 시간 분산해서 담는 것까지는 원칙의 영역인데, 그게 100건 넘게 쌓이면 그다음부터는 **관리의 영역**이더라고요. 저도 175건 되기 전까지는 몰랐던 부분입니다.

이 글은 어떤 상품이나 서비스를 사시라는 게 아니고, 그냥 제가 실제로 이렇게 관리하고 있다는 걸 공유드리는 거예요. 궁금하신 거 있으시면 댓글 남겨주세요.

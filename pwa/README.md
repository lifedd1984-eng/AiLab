# 빠른 체크리스트 — PWA (설치형 웹 앱)

카테고리·줄긋기 유지·완료 히스토리를 그대로 구현한 웹 버전입니다. 회원가입도, App Store/서명도
필요 없이 **브라우저에서 홈 화면에 추가**하면 아이콘을 탭해 전체 화면 앱처럼 열립니다.

**단, 홈 화면 위젯은 iOS/Android 정책상 PWA로 만들 수 없습니다** — 위젯이 필요하면 `ios/`,
`android/`의 네이티브 앱을 쓰세요. PWA는 "설치 마찰 없이 지금 바로 써보기" 용도에 가깝습니다.

## 배포 (CI 자동, 1회 설정 필요)

`.github/workflows/pwa-deploy.yml`이 `pwa/` 변경 시마다 GitHub Pages로 자동 배포합니다.
최초 1회만 저장소 설정이 필요합니다:

1. 저장소 → **Settings → Pages**
2. **Source**를 "GitHub Actions"로 변경 (Deploy from a branch가 아님)
3. 저장 후 Actions 탭에서 "Deploy PWA to GitHub Pages" 워크플로가 자동 실행됨
4. 완료되면 `https://lifedd1984-eng.github.io/test1/` 에서 접속 가능 (URL은 Settings → Pages에도 표시됨)

## 설치 방법

**아이폰 (Safari 필수 — Chrome 등에서는 "홈 화면에 추가"가 없음)**
1. Safari로 배포 URL 열기
2. 하단 공유 버튼(⬆️) → **"홈 화면에 추가"**
3. 홈 화면 아이콘 탭 → 주소창 없이 전체 화면으로 열림

**갤럭시/안드로이드 (Chrome)**
1. Chrome으로 배포 URL 열기
2. 우측 상단 메뉴(⋮) → **"앱 설치"** 또는 자동으로 뜨는 설치 배너
3. 앱 서랍에 아이콘 생성, 네이티브 앱처럼 실행

## 데이터

기기 로컬(`localStorage`)에만 저장됩니다 — 서버 없음, 계정 없음. 다만 **기기 간 동기화가 안 되고,
브라우저 데이터를 지우면 함께 사라집니다.** 오프라인에서도 열리도록 서비스 워커로 캐싱됩니다.

## 네이티브 앱과의 관계

`ios/`, `android/`와 기능은 동일(카테고리·체크 유지·히스토리)하지만 별도 코드베이스입니다.
기능을 추가할 때는 세 곳(`pwa/index.html`, `ios/`, `android/`)을 함께 수정하세요.
